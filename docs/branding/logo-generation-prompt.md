# Logo generation prompt

Daniel supplied the final logo as an image (`Brand/reference/voxara-brand-sheet.png`), so no generation prompt was used. The direction below is kept for future revisions.

Design direction for reference (from the Voxara brief):
- Combine human voice, text, AI/system thinking, speed and precision.
- Suggested direction: an abstract V formed where a voice waveform meets a text cursor / signal path.
- Avoid: a microphone silhouette as the whole logo, chat bubbles, brains, robots, sparkles, waveform clichés, the letters "AI", and anything resembling Wispr Flow, OpenAI or Anthropic marks.
- It must stay recognizable at Dock and menu-bar sizes.
