# Voxara brand assets

- `logo/`: the master logo artwork. Drop a square PNG here, at least 1024×1024 with a transparent or solid background.
- `icons/`: generated macOS icon set (`Voxara.icns`) and menu-bar template images. Build them with `scripts/make-icon.sh` once a logo exists.
- `reference/`: mood and reference images. Not shipped.

Visual direction: deep charcoal / near-black, warm white, subtle grays, and one controlled orange accent (an orange→amber gradient only for special emphasis). Native system typography. Design tokens live in `Sources/VoxaraApp/DesignSystem/Tokens.swift`.
